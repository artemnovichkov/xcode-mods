# xcode-mods

Claude Code mods for iOS dev over headless Xcode MCP. See README.md.

- One plugin `mods/xcode-mods/` (`.claude-plugin/plugin.json`, `hooks/hooks.json`, `types/index.d.ts`, `tests/`). `hooks.json` allows one module: `hooks/register.tsx` calls `build.tsx` and `canvas.tsx`. `$` can't cross imports, so all slash commands are registered in `build.tsx` `setup`. Load the `plugin-authoring` skill before editing. Run with `claude --plugin-dir mods/xcode-mods` (watched → hot reload on save).
- Check before commit: `claude plugin validate mods/xcode-mods`, `claude plugin test mods/xcode-mods`.
- Xcode MCP server is `xcode` (`.mcp.json`). Headless mode: tools take `workspaceIdentifier` (use id from `XcodeOpenWorkspace`/`XcodeListWorkspaces`; abs path not reliable), not `tabIdentifier`.
- Test app: `Sandbox/Sandbox.xcodeproj`, scheme `Sandbox`. Generated by XcodeGen from `Sandbox/project.yml`; don't edit the pbxproj by hand.
- Research notes, ideas, roadmap: `docs/PLAN.md`. Read it first. Done: `build.tsx` (Build · Run · Tests pane, toolbar band, `/build`, `/run`, `/tests [filter]`, `/stop`, `/xcode`), `canvas.tsx` (`/preview` → SwiftUI preview pane).
